# Azure Communication Service
This guide outlines the process of setting up an SMTP service in Azure to address ongoing email service issues within WordPress. Below are the detailed steps to configure the service effectively.

## Step1: App Registration Creation
Begin by creating an app registration, named "onecloud-smtp-app". Secure the Client ID and secret generated during this process.

App Name: onecloud-smtp-app
Client Id: 6ba6ea34-8ac6-444f-bfe6-389d213f5796

## Step2: Azure Email Communication Service Setup
Create an Azure Email Communication Service named "aksoc-email-srv". Configure it by adding a custom domain (e.g., cloudblogsemail.microsoft.com) and a "from" email address (e.g., donotreply@cloudblogsemail.microsoft.com).

## Step3: Azure Communication Service Setup
Next, create an Azure Communication Service named "aksoc-commn-srv". Under the Email > Domain section, incorporate the previously created email service and its designated domain.

## Step4: Custom Role Creation
Develop a custom role by cloning the "Reader" role within Azure Communication Service, named "SMTP Relay Role". Grant the following "Azure Communication Service" permissions to this role:
- Read : Gets/Lists registered subscriptions
- Write : EmailService_CreateOrUpdate

## Step5: Role Assignment
Assign the custom role ("SMTP Relay Role") to the App Registration "onecloud-smtp-app" within the Azure Communication Service "aksoc-commn-srv".

## Step6: Final Configuration
At this point, you are ready to consume the service by using the following SMTP configuration in your application code.
- **SMTP Host:** smtp.azurecomm.net
- **SMTP Port:** 587
- **User:** [Azure Communication Service Name].[App/Client ID].[Tenant ID] 
    - Example: aksoc-commn-srv.6ba6ea34-8ac6-444f-bfe6-389d213f5796.72f988bf-86f1-41af-91ab-2d7cd011db47
- **Password:** [App Registration Secret]
- **From Email:** donotreply@cloudblogsemail.microsoft.com

Note: The email address domain must match to the domain configuration in Step2.
