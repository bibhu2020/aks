# Checklist for Cluster Health

- [ ] Make sure Nodes are configured to auto-patch (Saturday for Stg, Sunday for ppe, Tuesday for prd)
- [ ] Kured daemonset is installed (this reboots the node VMs when needed)
- [ ] Ensure the cluster is on N-2 version
- [ ] Diagnostic logging is configured (East cluster on East WS, West cluster on West WS)
- [ ] Grafana monitoring is configured with zone-redundancy
- [ ] Local Account access is removed from the cluster
- [ ] Implement Network Policy
- [x] Verify node access through ssh
- [x] Verify the private endpoint access from the respective VNET for SQL Server, key vault and storage accounts
- [x] Make sure the ingress fake certificate is replaced (https://10.240.20.42)



# Monitoring
- Add prometheus and grafana to apps folder. 
- Add app insight

# Private DNS
- must have created both for east and west
- privatelink.file.core.windows.net
- privatelink.mysql.database.windows.com 

# Key Vault
- Must have the public access disabled
- Azure Services Allowed
- AKS subnets (both east and west subnet for KV) added
- KV is mounting to POD

# Storage Account
- Public access disabled
- Private endpoint (both for east and west) is created
- ping to storage from east must resolve to FQDN / A-record in east private DNS
- ping to storage from west must resolve to FQDN / A-record in west private DNS
- Verify mounting

# Worker Nodes
- Verify worker nodes are accessible using SSH keys in Key Vault

# VM
- verify login into VMs (east and west)

# MySQL Server
- Public access disabled
- Private endpoint (both for east and west) is created
- ping to storage from east must resolve to FQDN / A-record in east private DNS
- ping to storage from west must resolve to FQDN / A-record in west private DNS
- Verify SQL server access from VM
